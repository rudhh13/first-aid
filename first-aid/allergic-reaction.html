Steps for Treating an Allergic Reaction

  1. Identify the allergen and remove it if possible.
  2. Give an antihistamine (such as diphenhydramine) if mild symptoms appear.
  3. Help the person stay calm and seated in a comfortable position.
  4. If severe symptoms develop (difficulty breathing, swelling, dizziness), use an epinephrine auto-injector (EpiPen) if available.
  5. Call emergency services immediately if symptoms worsen or do not improve.

💊 Recommended Medications:

  • Antihistamines: Diphenhydramine (Benadryl), Loratadine
  • Epinephrine (for severe reactions): EpiPen, Adrenaclick
  • Bronchodilators (if breathing is affected): Albuterol inhaler
